# Tarkeeba brand notes

## Positioning

Tarkeeba is a provider-neutral desktop workspace for autonomous coding agents. The name describes a coordinated system that turns specifications into working software, without tying the product to Claude, Codex, Anthropic, or OpenAI.

Primary line: **Plan, build, and validate with the coding agent you choose.**

## Product identity

- Product name: `Tarkeeba`
- Package slug: `tarkeeba`
- Application ID: `io.github.mohamedjanemr.tarkeeba`
- Current release repository: `mohamedjanemr/tarkeeba`
- Initial beta: `2.8.0-beta.1`

The checked-in icon assembles a connected `T` inside a hexagonal cell. The warm lime signal color keeps continuity with the existing interface while the modular geometry expresses several parts working as one composition.

## Compatibility names

Do not rename these in the 2.8 release:

- `.auto-claude/` project directories
- `auto-claude/*` task branch prefixes
- the legacy `auto-claude-ui` production user-data directory
- established IPC channels and persisted setting keys

These are internal compatibility contracts, not visible product branding.

## Before public launch

- Complete a trademark search in target markets; the current name check is preliminary only.
- Register the desired domain and social handles.
- Configure branch protection, release environments, and signing secrets in the standalone `tarkeeba` repository.
- Confirm the legal publisher name shown in signed macOS and Windows builds.
- Capture fresh Tarkeeba screenshots to replace the inherited interface images.
- Add a privacy policy and support contact before collecting telemetry or offering hosted services.
- Do not use Anthropic or OpenAI logos, and do not imply endorsement.
